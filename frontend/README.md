# SignalAyiti, front-end (React)

Interface web du projet SignalAyiti. Voir le [README principal](../README.md) pour la
presentation complete du projet.

## Demarrage rapide

```bash
npm install
cp .env.example .env
npm run dev
```

L'application est alors disponible sur `http://localhost:5173`. Elle attend l'API
Laravel sur `http://127.0.0.1:8000/api` (modifiable dans `.env`).
